エージェント経営とは

「エージェント経営」とは、AIエージェント（自律的に判断・実行するAIシステム）に日常業務を委任し、 人間は戦略立案・意思決定・関係構築に集中する経営スタイルです。

当社では Claude（Anthropic社） をコアエンジンとして、 楽天・Amazon・Yahoo!の受注管理、広告最適化、レポート生成、ブログ投稿など 複数のビジネスプロセスを自動化しています。

「ルーティンはエージェントへ、創造と判断は人間へ」― これが私たちの経営哲学です。

🛒EC受注統合エージェント

毎朝8時に全モールの注文データを自動取得・統合
  • 楽天 RMS API から注文データ取得
  • Amazon SP-API から注文・売上データ取得
  • Googleスプレッドシート「注文統合」シートへ書き込み
  • 重複排除・キー名正規化の自動処理
  • Yahoo・自社・グースリー統合（CSV手動運用中）

📢楽天RPP広告エージェント

楽天RPP広告のデイリー入札最適化を自動実行
  • 週次CSVデータ取込・KPI集計
  • キーワード別CPC・CVR分析
  • 入札価格の自動調整提案
  • 100クリック未満キーワードは停止提案禁止（ルール遵守）
  • DRY_RUN=true 稼働中（本番適用承認待ち）

📊楽天週次レポートエージェント

楽天の売上・広告データを毎週自動集計
  • RMSレポートCSV自動読み込み（Node.js）
  • KPI自動計算（売上・セッション・CVR・RPP効果）
  • Googleスプレッドシートへ自動書き込み
  • run_weekly.bat / .ps1 で定期実行

🔵Amazon月次レポートエージェント

Amazon広告の月次レポートをSP-APIから自動取得・分析
  • SP全レポート取得（KW・ASIN・検索語句）
  • CTR / CPC / ACOS / ROAS 自動計算
  • Googleスプレッドシートへ自動出力（Python）
  • childAsin優先・parentAsinフォールバック処理

🟡Yahoo週次レポートエージェント

Yahoo!ショッピングの売上・広告データを毎週集計
  • 毎週月曜9時：Google DriveのCSVを自動読み込み
  • 売上・広告データ自動書き込み
  • SEO順位取得・記録
  • 手動5分：月曜にCSV DL → Drive保存

✍️ブログ自動投稿エージェント

Goosely公式ブログに週3回、SEO最適化記事を自動投稿
  • 月初に翌月記事カレンダーを自動生成
  • 月曜：教育コンテンツ記事生成・投稿（7:00）
  • 水曜：比較・レビュー記事生成・投稿（7:00）
  • 金曜：ライフスタイル記事生成・投稿（7:00）

🎙️音声教育化エージェント

  • Vimeo音声ダウンロード自動化

  • Claude APIによる概念・ナレッジ抽出
  • Vimeo動画・lessons.json 未投入（実行待ち）

📋週次ダッシュボードエージェント

  • Claude API でサマリー生成

エージェント経営の3原則
01
自動化ファースト
新しい業務が生まれたとき、まず「これはエージェントに任せられるか？」を問う。ルーティンは即自動化を検討する。
02
人間は戦略・承認のみ
AIの実行結果を人間がレビュー・承認する体制を維持。完全自律ではなく「人間in the loop」で品質と安全を担保する。
03
記録・継続改善
各セッションの作業をCLAUDE.mdに記録し、エージェントが次回も文脈を引き継げる状態を維持する。知識の蓄積が競争優位になる。
